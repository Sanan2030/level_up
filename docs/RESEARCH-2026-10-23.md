## Technical distinctions reviewed

- An image digest identifies content; it does not independently certify a trusted build. A mutable tag can change. Docker `--no-cache` and pulling a newer base are separate concerns.
- Removing a secret in a later image layer does not erase earlier layer contents. Build and runtime secrets need suitable handling.
- A passing PR job is not release authority. Executing untrusted code with deployment credentials crosses a trust boundary. OIDC still needs a constrained trust policy.
- Readiness controls normal Service traffic eligibility; liveness failures can restart a container; startup probes gate initialization. A Deployment progress deadline reports failure and does not guarantee complete automatic rollback or database recovery.
- Terraform sensitive marking is redaction, not a promise that a value is absent from state. State locking depends on backend support. Plans describe changes rather than certify safety.
- A 99.9% request-success SLO over 100,000 eligible requests permits 100 failed requests. Eighty failures leave 20 failed requests of budget, not 20 minutes. A 95-minute restoration from a 40-minute-old recovery point misses a 60-minute RTO and a 15-minute RPO.
- SQL joins can multiply header amounts. A distinct sum of amounts is not a reliable deduplication by entity. Window ordering and final output ordering differ; default ordered frames can include peers.
- Missing and zero are different. pandas may match null join keys; ordinary SQL equality does not. Merge cardinality should be checked before aggregating.
- Cohort entry, activity, denominator and observation cutoff are separate definitions. Unobserved future activity is not zero retention. A previous row is not necessarily the previous calendar month.
- Power Query locale affects date/number interpretation. Measures respond to filter context; averaging subgroup percentages generally differs from aggregating their numerators and denominators.
- The A/B calculation is an original unpooled normal approximation with independent account assignments and a fixed horizon. The selected NIST overview does not supply a complete online experimentation method. Positive observed lift is not proof of a positive effect, and non-significance is not proof of equivalence.
- Color labels address one accessibility requirement; contrast, keyboard access and accessible values remain separate considerations.
