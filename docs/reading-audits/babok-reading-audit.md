## Scope decisions

- The 2015 guide is the source for professional concepts and tasks, not evidence that historical BABOK knowledge-area coverage equals the current ECBA exam blueprint. Each ECBA lesson explicitly preserves that distinction.
- The lessons distinguish elicitation confirmation, requirement verification, requirement validation, authorized approval, potential-value estimation and evaluation of an actual solution.
- Diagrams and numerical-free scenarios are original teaching aids, not reproductions of the guide's diagrams, tables or exam questions.
- The user subsequently requested English-only visible content. All nine English lessons are complete (approximately 830–1,045 whitespace-delimited words including frontmatter, source notes and diagram labels). Six AZ translations already authored before steering were saved in the existing content files as archive/source; the remaining three CBAP AZ outlines were left unchanged. Parent owns English-only routing and validation decisions.
- Proposed metadata is in `/tmp/babok-lesson-metadata.json`; no shared data catalog or source registry was changed by this agent.
